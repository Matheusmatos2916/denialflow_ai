# UnifiedCare — Coding & Modifier Reference (Synthetic)

**Reference:** UC-CODING-2025-01  
**Focus:** Modifier 59, X{EPSU} modifiers, and bundling edits.

## Guidance
When services are distinct procedures on the same day, documentation must support distinct sessions or anatomical sites.

## Denial patterns
- Duplicate claim submissions for the same DOS/CPT without modifier support
- Unbundling denials when NCCI edits apply

## Appeals
Provide operative report excerpts, distinct diagnosis pointers, and NCCI justification when clinically supported.
